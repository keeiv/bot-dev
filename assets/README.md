# bot-dev 圖標

| 檔案 | 用途 |
| --- | --- |
| `bot-dev-mark.png`／`.svg` | 只有標誌（透明背景） |
| `bot-dev-wordmark.png`／`.svg` | 標誌加 BOT.dev，字是深色，用在淺色背景；自述文件與貢獻指南的標題 |
| `bot-dev-wordmark-light.png`／`.svg` | 同上，字是淺色，用在深色背景 |
| `icon.png`／`.svg` | 圓角方形底的版本，給插件目錄的圖示（`plugin.json` 的 `icon`） |

標誌是 [BOT.](https://github.com/keeiv/bot) 的標誌被一對角括號夾住：左邊用標誌的暖色、右邊用冷色，和 BOT. 英文版軌道的配色走向相同。角括號代表程式碼，意思是「在程式碼裡陪著 BOT.」。

字樣沿用 BOT. 的寫法：`BOT.` 的筆畫、大寫高度與洋紅句點完全相同，後面的小寫 `dev` 用同樣粗細的筆畫畫成，末端平切、轉角圓滑。角括號的筆畫也是同一個粗細，所以標誌和字樣讀起來是一體的。

形狀與顏色取自 BOT. 倉庫的 `assets/logo/generate.py`。PNG 由 SVG 轉出，背景透明。
